▤ O que o sistema faz

visão para os times
Backend único que centraliza três integrações externas atrás de endpoints REST próprios. O cliente da API só conversa com o padrão interno (DTOs, ISO 8601, erros RFC 7807) — nunca com o formato específico do provedor. Cada provedor tem um client próprio e o formato dele não vaza para o domínio.
Contratos: gera o PDF do contrato no APITemplate.io e guarda o link.  ·  Imagens: sobe a imagem uma vez no Cloudinary e devolve versões editadas por transformação na URL (sem novo upload).  ·  Agenda: CRUD de eventos no Nylas v3 — a agenda é a fonte da verdade (não há tabela própria).

▤ Fluxo de dados

requisição até o provedor
Regra de ouro: nenhuma transação de banco aberta durante chamada HTTP — o serviço salva PENDENTE, chama o provedor fora da transação e depois salva GERADO/FALHA.
